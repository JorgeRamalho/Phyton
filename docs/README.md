# Documentação do projeto PhytonFree

Documentação de produto e engenharia. Destina-se a quem desenvolve, organiza ou publica o portal — não ao aluno na trilha.

A documentação da **linguagem Python** para o aluno está em `pages/docs.html`.

## Leitura recomendada

1. [Pesquisa](01-pesquisa.md) — problema, público, referências e decisões de produto
2. [Planejamento](02-planejamento.md) — escopo, páginas, conteúdo e critérios de pronto
3. [Arquitetura](03-arquitetura.md) — camadas, persistência, navegação e SEO
4. [Estrutura](04-estrutura.md) — pasta raiz enxuta e arquivo em cada pasta de origem
5. [Convenções](05-convencoes.md) — como adicionar página, estilo, script ou ativo

## Princípio

A raiz do repositório é a fachada: entrada do site e arquivos de configuração. Código, páginas internas, marca e este dossiê ficam em pastas nomeadas pela responsabilidade de cada arquivo.
